# Гаманець

Особистий облік витрат і доходів — простий аналог Monefy. Працює як вебзастосунок (PWA):
встановлюється на iPhone з Safari, працює без інтернету, усі дані зберігаються лише на телефоні.

## Встановлення на iPhone
1. Відкрийте адресу застосунку в **Safari**.
2. Кнопка «Поділитися» → **«На початковий екран»** → «Додати».
3. Запускайте з іконки «Гаманець», як звичайний застосунок.

## Перенесення історії з Monefy
1. Monefy → Налаштування → **Експорт у файл** → «Зберегти у Файли».
2. Гаманець → ⚙ → **Імпорт з Monefy** → оберіть файл → перевірте підсумок → «Імпортувати».

## Резервна копія
⚙ → «Зберегти резервну копію» (JSON) — зберігайте у Файли/iCloud. Відновлення там само.

## Розробка
```
node tools/serve.mjs 8765   # локальний сервер
npm test                    # тести
npm run icons               # перегенерувати іконки
```
При зміні файлів збільшуйте `VERSION` у `sw.js` і `APP_VERSION` у `js/app.js`.
