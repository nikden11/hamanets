# Гаманець — особистий облік витрат (аналог Monefy)

## Мета
Власний додаток для iPhone замість Monefy, який далі кастомізуємо під себе.

## Дані й файли
- PWA без збірки: `index.html`, `css/app.css`, `js/*.js` (ES-модулі), `sw.js` (офлайн), `manifest.webmanifest`, `icons/`.
- `js/util.js` — гроші (цілі копійки), дати `YYYY-MM-DD`, періоди, калькулятор без eval.
- `js/calc.js` — чисті розрахунки (баланси, зведення, бюджети, курси). `js/monefy.js` — імпорт CSV Monefy.
- `js/db.js` — IndexedDB (`hamanets`), сторони: accounts, categories, txs, budgets, meta.
- `js/app.js` — весь інтерфейс (рендер рядками HTML, делегування подій `data-a` / `data-in`).
- Тести: `npm test` (node:test, `tests/core.test.mjs`). Іконки: `npm run icons`.
- Локальний запуск: `node tools/serve.mjs 8765` (python http.server не має доступу до Documents).

## Методика / ключові рішення (і чому)
- PWA, а не SwiftUI: на Mac немає Xcode; безкоштовний Apple ID дає підпис лише на 7 днів. PWA ставиться з Safari «На початковий екран», працює офлайн.
- Хостинг: GitHub Pages (обрано Денисом). Фінансові дані лише в IndexedDB телефона, у репо — тільки код.
- Суми — цілі копійки (без похибок float). Перекази не є доходом/витратою.
- Базова валюта (UAH) для «Усі рахунки» і бюджетів; курси = скільки базової за 1 одиницю; щодня автооновлення з НБУ
  (bank.gov.ua, CORS працює), ручна правка курсу вимикає автооновлення.
- Імпорт Monefy: авто-визначення роздільника/десяткового знака/формату дати; витрати = від'ємні суми;
  перекази "To 'X'"/"From 'Y'" зводяться в пару; "Initial balance" → початковий баланс рахунку;
  дедуплікація за ключем (дата|рахунок|категорія|сума|опис#n) — повторний імпорт безпечний.
  Точний формат експорту Monefy не перевірено на реальному файлі — чекаємо зразок від Дениса.
- Кільце категорій на головній: до 14 категорій витрат (решта через «Ще»), порядок — у Налаштування → Категорії.
